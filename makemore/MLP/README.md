# MLP 名字生成模型

本目录对应 **makemore** 系列中的 MLP（多层感知机）名字生成模型，主要参考 Bengio 等人 2003 年提出的神经网络语言模型思想。

## 论文

- 文件名：`bengio03a.pdf`
- 标题：*A Neural Probabilistic Language Model*（《一种神经概率语言模型》）
- 作者：Yoshua Bengio, Réjean Ducharme, Pascal Vincent, Christian Jauvin
- 年份：2003
- 说明：该论文是神经网络语言模型的奠基性工作之一，提出了通过神经网络学习词嵌入并建模词序列概率的方法，对后续深度学习在自然语言处理中的应用影响深远。

> 注意：`bengio03a.pdf` 为本地参考文件，已加入 `.gitignore`，不会推送到 GitHub。
